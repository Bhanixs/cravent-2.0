# Cravent Nexus

Build a high-end, modern, futuristic website prototype for Cravent, a business growth partner combining Branding, Marketing, Business Development, Strategy, and Technology.

1. CORE BRAND POSITIONING

Cravent is a growth partner for ambitious businesses that are building something meaningful: a brand, business, institution, platform, or movement.

Core positioning:

Design. Marketing. Strategy. Technology.

Core belief:

Growth should not feel disconnected.

The brand should support marketing.
Marketing should support sales.
Sales should inform technology.
Technology should make growth easier to manage.

Cravent's role is to understand where a business is today, identify what is holding it back, and build the creative, strategic, and technical systems needed for the next stage.

The website should feel like a premium futuristic growth-tech company, not a generic marketing agency.

Do NOT make it look like a generic SaaS dashboard.

Do NOT use soft pastel colors.

Do NOT use generic stock photos of smiling business people.

The construction strategy specifically describes Cravent's identity as electric blue, futuristic, angular, and bold, with geometric/architectural visuals and an X-mark motif.

The visual personality should communicate:

"We build the systems behind what comes next."

3. TYPOGRAPHY

Use a modern geometric sans-serif.

Recommended:

Headings: Space Grotesk / Sora / similar geometric display font

Body: Inter / similar clean sans-serif

Use:

Large oversized headings

Bold uppercase or sentence-case display typography

Occasional italic emphasis

Tight heading line-height

Strong contrast between headline and supporting text

Typography should feel architectural and engineered rather than soft or playful.

7. "WHAT WE DO" SECTION

03 — BUSINESS DEVELOPMENT & STRATEGY

8. CRAVENT APPROACH

Create a horizontal / sequential section showing:

UNDERSTAND → DEFINE → BUILD → LAUNCH → IMPROVE

Descriptions:

Understand

Study the business, audience, market, competition, current systems, and growth priorities.

Define

Identify the core opportunity, clarify positioning, and define the scope of work.

Build

Create the brand, campaign, strategy, platform, CRM, or digital system required.

Launch

Put the work into the market through campaigns, content, partnerships, technology, and sales systems.

Improve

Review performance, learn from the market, and improve the system over time.

Make this section visually feel like an engineered process / system pipeline.

19. 3D IMPLEMENTATION

If actual 3D is practical in the prototype, use:

Three.js / React Three Fiber

Use lightweight geometric/architectural 3D objects rather than a huge realistic building model.

If actual 3D is not practical, create a convincing simulated 3D visual using CSS, gradients, SVG, canvas, or lightweight assets.

The prototype must remain performant.

For a future production implementation, the construction architecture can use:

React / Next.js → React Three Fiber / Three.js → WebGL → GLTF/GLB assets created in Blender.

Do not build a full production 3D engine for this prototype.

20. RESPONSIVENESS

The prototype must work beautifully on:

Desktop

Tablet

Mobile

Desktop should be the primary presentation experience.

Mobile should preserve the visual hierarchy without simply shrinking desktop layouts.

21. UX PRINCIPLES

The website should feel:

Clear, confident, immersive, premium, technical, and conversion-focused.

Avoid:

Generic agency templates

Excessive rounded cards

Pastel gradients

Corporate stock imagery

Excessive glassmorphism

Cluttered dashboards

Tiny typography

Excessive text blocks

Fake statistics

Unverified client results

Use real content from the supplied Cravent material wherever possible.

Do not invent statistics, testimonials, awards, client results, or business claims.

22. IMPORTANT BRAND RULE

Do NOT soften the Cravent identity for construction.

The supplied construction strategy explicitly describes the brand as:

Electric blue on black. Geometric. Angular. Skyline motifs. X-mark at scale. Bold typography. Dark dramatic architectural renders.

The brand archetype is:

The Architect

The primary emotion should be:

Confidence

The voice should be:

Declarative, precise, direct, confident.

Avoid hesitant language such as "we help you explore possibilities."

Prefer direct language such as:

"We build your digital growth infrastructure."

23. OVERALL EXPERIENCE

The final website should feel like entering a futuristic architectural command center for business growth.

It should communicate three things within the first few seconds:

Cravent understands business.

Cravent can build the creative and strategic systems around that business.

Cravent can actually build the technology too.

The website should therefore combine:

Creative agency + strategic consultancy + technology studio + futuristic architecture.

Do not make it feel like four disconnected companies.

Make everything feel like one integrated system.
